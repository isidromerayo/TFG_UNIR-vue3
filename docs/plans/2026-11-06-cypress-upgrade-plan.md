## 📋 Resumen

Este documento describe el plan para actualizar Cypress en el proyecto Vue3. Actualmente está en versión 15.21.1 y necesita ser actualizado a 16.2.1 junto con @cypress/code-coverage.

**Inversión Estimada:** 3-4 horas

4. **Verificar** compatibilidad con Vite 7.3.7
5. **Verificar** configuración ESM en cypress.config.ts

### Configuración Actual
```typescript
// cypress.config.ts (ESM)
import { defineConfig } from 'cypress'
import registerCodeCoverageTasks from '@cypress/code-coverage/task'

export default defineConfig({
  e2e: {
    specPattern: 'cypress/e2e/**/*.{cy,spec}.{js,jsx,ts,tsx}',
    baseUrl: 'http://localhost:5173',
    setupNodeEvents(on, config) {
      registerCodeCoverageTasks(on, config)
      return config
    },
  },
  component: {
    devServer: {
      framework: 'vue',
      bundler: 'vite',
    },
    setupNodeEvents(on, config) {
      registerCodeCoverageTasks(on, config)
      return config
    },
    env: {
      coverage: process.env.CYPRESS_COVERAGE === 'true'
    }
  },
})
```

### Tests Actuales
- **Component tests:** En `cypress/component/`
- **E2E tests:** En `cypress/e2e/`
- **Unit tests:** Vitest (25 suites / tests)

## 🎯 Decisiones de Diseño

### Versión de Cypress
**Decisión:** 16.2.1 (última versión estable)
**Razón:**
- Compatible con Vite 7.3.7
- Mejoras en performance y debugging
- Versión soportada activamente

### Orden de Actualización
**Decisión:** React primero, luego Vue3, luego Angular
**Razón:**
- React valida el enfoque
- Vue3 similar a React en complejidad
- Angular requiere más investigación (component testing)

### Configuración ESM
**Decisión:** Mantener configuración ESM
**Razón:**
- Ya funciona correctamente
- Compatible con Cypress 16
- Estándar del proyecto
